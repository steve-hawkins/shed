OpenTelemetry + .NET Aspire

Observable locally and in any OTLP pipeline.

Shed is instrumented via Shed.ServiceDefaults so traces, metrics, and structured logs work out of the box with both the local .NET Aspire Dashboard and an OpenTelemetry Collector.

Traces

ASP.NET Core & Page Spans

Captures HTTP request traces plus custom shed.web.page.render spans tagged with canonical page names, excluding noisy health probes.

Metrics

Runtime & Page Counters

Exports ASP.NET Core, HTTP client, .NET runtime metrics, and the bounded shed.web.page_views counter.

Exporters

Aspire + OTel Collector

Honors standard OTEL_EXPORTER_OTLP_ENDPOINT (gRPC & HTTP/protobuf) and optionally dual-exports via OTEL_COLLECTOR_ENDPOINT.

Run locally

# 1. Run with local .NET Aspire Dashboard
dotnet run --project src/AppHost

# 2. Run standalone against an OpenTelemetry Collector (gRPC :4317 or HTTP :4318)
OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318 \
OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf \
dotnet run --project src/Web

# 3. Run under Aspire Dashboard AND simultaneously forward to an OTel Collector
OTEL_COLLECTOR_ENDPOINT=http://127.0.0.1:4318 \
dotnet run --project src/AppHost
